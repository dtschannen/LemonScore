# 🍋 LemonScore

**LemonScore** is a sleek and modern **football scoreboard** app designed to help users easily **track live matches**, **follow standings**, and engage with key **football stats** — all wrapped in a clean user interface.

For full reference, setup instructions, and configuration options, head over to the [official documentation](https://docs.lemon-score.ch).
